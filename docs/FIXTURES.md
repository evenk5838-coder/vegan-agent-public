# 测试与内容样例

`backend/tests/fixtures/`中的供应商形状样例只用于离线回归；不构成餐厅认证，也不承诺地图覆盖率。

为保持现有测试入口，以下文件保留原相对路径：

- `知识库/候选/首批知识条目-2026-10-24.json`：7条未发布结构样例，包含本产品饮食分类规则与带来源的简短说明，不会自动发布为食材期限规则。
- `知识库/保留菜谱20道-2026-10-28/20道-原始来源核对.json`及`source-text/`：HowToCook的20道来源核对测试材料，固定来源版本，遵循该来源的Unlicense。测试中的未批准状态是回归夹具，不是当前本地账号的发布记录。
- `evidence/全量收口-2026-10-27/W05真实模型引用-脱敏响应.json`：公开副本已经用简短合成文字替换历史模型回答，只保留引用遗漏的协议形状。文件名沿用测试接口，不表示包含真实用户对话。

`samples/howtocook-20.json`提供可选的20道草稿示例，移除了业务记录ID及私人发布操作信息。用现有导入脚本只会导入为草稿；它不会迁移开发者的数据库，不会自动发布内容。来源与许可见根目录ASSETS.md。

没有收录旧批量外文菜谱、翻译库、私人验收截图、录音、精确用户定位或授权账本。
